# 🏠 House Rental Management System

A Java & MySQL-based application that helps manage house rentals efficiently. This system provides a user-friendly interface for users to browse available properties and for admins to manage rental records.

## 🚀 Features

### 🧑‍💻 User Module
- User registration and login
- View list of available houses/apartments for rent
- Filter/search houses based on location, price, and size
- Request a rental or book a house
- View booking history and status

### 🔐 Admin Module
- Admin login
- Add, update, or delete house listings
- View and manage rental requests
- Approve or reject user bookings
- Generate reports of rented properties

## 🛠️ Tech Stack

- **Frontend:** Java Swing / JavaFX (for GUI)
- **Backend:** Java (JDBC)
- **Database:** MySQL
- **Tools:** IntelliJ IDEA, MySQL Workbench
